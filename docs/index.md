## 이 스터디는 이렇게 진행합니다

C언어를 처음 배우면 낯선 영어 단어와 기호가 많이 보입니다. 처음부터 모두 외울 필요는 없습니다.

먼저 **"이 코드는 이런 일을 하는구나"** 정도를 이해하고, 직접 실행해 본 뒤 조금씩 익숙해지는 것을 목표로 합니다.

처음 참여하시는 분은 1주차 강의를 보기 전에 **Visual Studio 설치 준비**부터 진행해 주세요.

**[Visual Studio 다운로드부터 시작하기 →](/setup/download)**

### 코드 복사 방법

강의 중 아래처럼 코드가 나오면 코드 상자의 **오른쪽 위 복사 버튼**을 누르면 됩니다.

```c
printf("안녕하세요!\n");
```

복사한 코드는 Visual Studio에 붙여 넣어서 사용할 수 있습니다.

::: tip 기억할 것
처음 공부할 때는 코드를 직접 모두 입력하는 것보다, 먼저 **복사해서 실행해 보고 한 부분씩 바꾸어 보는 방법**도 매우 좋은 학습 방법입니다.
:::
